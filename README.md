# Softorino Email Bot

Automated email support for `support@softorino.app`, built as a Python 3.11 Vercel serverless function.

## Project structure

```text
softorino-email-bot/
├── api/
│   └── process_email.py
├── requirements.txt
├── vercel.json
└── README.md
```
